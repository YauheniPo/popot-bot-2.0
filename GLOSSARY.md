# popot-bot-2.0

Словарь двух независимых компонентов: личного AI-оператора Hermes и
Telegram User Info Bot для просмотра доступных боту данных пользователя.

## Language

### Hermes

**Hermes Agent**:
Личный AI-оператор, который выполняет запросы пользователя, работает с
инструментами и делегирует подзадачи.

**Hermes Workspace**:
Дополнительный интерфейс работы с Hermes, его беседами, рабочими файлами
и командой Swarm.
_Avoid_: Dashboard, второй Hermes.

**Hermes Dashboard**:
Официальная панель управления Hermes и его настройками, сессиями и заданиями.

**Профиль Hermes**:
Отдельный рабочий контекст Hermes со своими настройками и историей.
Профиль сам по себе не является границей прав доступа.
_Avoid_: учётная запись пользователя, sandbox.

**Сессия Hermes**:
Беседа с Hermes и её история в рамках профиля; одна сессия может включать
несколько запусков обработки запросов.
_Avoid_: сессия авторизации, отдельный запуск.

**Запись запуска чата (Chat run record)**:
Сохранённые сведения об отдельном запуске запроса в сессии Workspace,
включая последнее известное состояние и вывод.
Наличие записи не подтверждает, что выполнение продолжается.
_Avoid_: активный агент, фоновый процесс.

**Нативный субагент**:
Исполнитель ограниченной подзадачи, делегированной главным агентом Hermes
в рамках исходного запроса.
_Avoid_: Swarm-воркер.

**Swarm**:
Команда постоянных ролевых исполнителей, которым пользователь назначает
задачи через Workspace.

**Swarm-воркер**:
Участник Swarm с назначенной ролью и отдельным профилем Hermes.

**Командный цикл (Team workflow)**:
Последовательное выполнение одного запроса нативными субагентами в ролях
Researcher, Executor и Reviewer с ограниченными раундами исправлений.
Итог предназначен исходной беседе пользователя с главным агентом.
_Avoid_: Swarm, постоянная команда воркеров.

### Telegram User Info Bot

**Telegram User Info Bot**:
Отдельный бот для предоставления пользователю отчёта о доступных данных
его Telegram-профиля в личном чате.
_Avoid_: Hermes, Telegram-интерфейс Hermes.

**Отчёт о пользователе (User report)**:
Сводка доступных боту данных отправителя и его личного чата, включая явно
переданные данные и сведения о недоступных разделах.
Отсутствие поля означает, что данные не получены, а не что свойства у пользователя нет.
_Avoid_: полный профиль пользователя, история личной переписки.

**Переданный контакт (Shared contact)**:
Контактная карточка, явно переданная боту и связанная Telegram с самим
отправителем; чужая карточка не считается его переданным контактом.
_Avoid_: автоматически полученный номер телефона.

**Переданная геопозиция (Shared location)**:
Координаты места, которые отправитель явно передал боту.
Точка может быть выбрана вручную и не подтверждает текущее местоположение отправителя.
_Avoid_: текущее местоположение пользователя, отслеживание пользователя.
