# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/YauheniPo/popot-bot-2.0/security/advisories/new)
rather than opening a public issue.

Do not include exploit details, credentials, or other sensitive data in a
public issue, pull request, or commit.

You can expect an initial response within 5 business days. If the report is
accepted, a fix will be developed and released before any public disclosure;
if declined, you'll get an explanation of why it isn't considered a
vulnerability.
